#+title: CARBON community-1.38-rc2 prerelease
#+options: ^:nil -:nil

Unofficial CARBON firmware, not a Kilpatrick Audio release. System identity:
=1.38-jwk-rc2=; numeric song version: 1.38 (unchanged since rc1). Use the
accompanying build record for exact source, checksum and toolchain.

* New since community 1.38 RC1

** Drum tracks
Tracks set to DRUM become a real drum editor:
- Pitch is locked: Transpose, scale, Bias and CCi transpose no longer move
  drum notes (stored values return when the track is set back to VOICE).
- General MIDI drum names (BD, SD, CHH, ...) in Step Edit and Region; a
  weak default that will often not match your drum machine.
- Drum lanes: hold a DRUM track button for a drum grid (kick at the bottom,
  velocity as brightness); it stays open while recording and shows the
  take live. In Step Edit a third view (hold Step Edit) edits the lanes:
  add/remove hits, velocity, gate, own delay, move a whole lane to another
  drum, and lane Fill/Rotate (Euclidean pulses aligned to your own hits).
- Steps switched off by Pattern or Euclidean density show black.
- Drums to CV/gate: with ABCD pairing, BD/SD/CHH/OHH go to pairs A-D, gate
  for the hit's length, CV = velocity.

** Editing
- Region editing in Step Edit: Shift + Motion Start left past "all slots"
  edits every playing step at once (pitch, velocity, gate, step delay). A
  pitch filter (Shift + Transpose) limits it to one note, for example "all
  hats quieter"; filtered delays move only those notes.

** Fixes
- Track and scene overviews could stop opening after loading a song from
  the panel.
- Undo in Step Edit Region now keeps the blue region display.
- Songs with invalid values are repaired on load (in RAM, with a notice);
  carbon-backup repairs on download and accepts a damaged upload target.

* Earlier in community 1.38 RC1

:END:

** A display that shows more
- Full-page menu overviews: hold Clock, Arp, MIDI, Tonality, or Shift then
  MIDI (System), for 800 ms. Motion Start selects a row, Length/Value edits
  it, with two lines of help. Short presses keep their normal actions;
  unshifted Arp, MIDI and Tonality now act on release, and a long Arp hold
  does not toggle the arp.
- Track overview: hold a track button for 800 ms to see that track in all six
  scenes (motion range, step length, Bias Track, mute, root and scale).
- Scene overview: hold Scene, then a number, for 800 ms to see that scene for
  all six tracks. The scene is still selected immediately as before.
- Expanded Step Edit: hold Step Edit for 800 ms to show Note, Vel, Gate and
  Dly for all six slots, plus Ratchet and the shared step delay.

** Editing and performance
- Arp Speed *Chord*: each step's notes trigger up to four simultaneous
  generated pitches, with scale-aware voicings for single notes.
- Humanize (Clock menu, per track, not saved): chance and amount of velocity,
  length and late-onset variation for sequenced notes and the arp.
- One-level song undo: hold Clock, then press Run/Stop. Step Edit groups each
  step visit into one undo point.
- Transposing a whole step in Step Edit now changes note pitches only;
  conditions, CCs and other events keep their values.
- Turning Pattern (ratchet) in Step Edit no longer plays a misleading single
  preview hit.

** Fixes
- Mini sequencers could be missing at startup until Step Edit was entered.

** Documentation and tools
- Illustrated user guide, reorganised by task: annotated display and Step
  Edit, anatomy of a step, the four event families, and cards for Prb, Euc,
  Hrm/Inv on a Bias track and Euclidean density. Screens are rendered by
  CARBON's own display code from example data (=tools/screenshots=).
- Host song tools support 1.38: JSON schema5/profile =carbon-1.38-arp-chord=,
  backup, validation, view, MIDI import (new default template) and simple
  upload; advanced restore uses =--firmware-community-1.38=.

All earlier community features remain included.

* Compatibility
:PROPERTIES:
:CUSTOM_ID: compatibility
:END:
Songs keep their 20480-byte size and the 1.37 layout. rc2 does not change
the song format: rc1 and rc2 songs are interchangeable, and the host tools
need no update. Songs saved with 1.38
are marked 1.38. A song using Arp Speed Chord cannot be played as intended on
1.37 or earlier firmware; keep pre-upgrade originals for older firmware.
Faithful downgrade is not supported.

The host tools refuse to relabel a 1.38 song as 1.37 or the reverse; there is
no automatic migration. 1.37 and 1.36 JSON remain supported.

Back up before installing or saving migrated songs. Host song replacement is
non-atomic across sectors and requires panel LOAD afterward, not saving stale
RAM. All target/approval/recovery/readback safeguards remain.

Use the README's dfu-util procedure at *0x08020000* to preserve the factory
bootloader. Never use stock dfu.sh, 0x08000000 or mass erase for this image.

* Evidence and limitations

The maintainer ran each development candidate leading to rc2 on hardware
and confirmed: DRUM pitch lock, drum names, Region filter (including
per-note delay and lane moves), Undo staying in Region, the lane overview
(also while recording), the lane view with add/remove/velocity/gate/delay,
lane move, Fill/Rotate, masked steps, and the drum CV map (CV on one port
while MIDI continues on the other). Testing is not exhaustive; Fill's
musical rules may be refined after wider use. The rc2 build differs from
the last tested candidate (=jwk-drm7=) only in its identity string.

Host tests cover gestures, display layouts for both LCD types, editor
behaviour, playback, CV output and JSON/transfer paths. Not yet recorded on
hardware: busy-load CPU and stack high-water; every synth, route and option
combination. See RELEASE-CHECKLIST.org.
